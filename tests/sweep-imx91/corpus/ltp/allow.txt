# LTP syscall test allowlist (stems). build.sh stages every built binary whose
# name matches ^<stem>[0-9] — i.e. the numbered variants of exactly that
# syscall. Curated to SAFE, deterministic, hardware-independent tests: nothing
# that changes global system state (no reboot/swapon/settimeofday/clock_settime/
# module-load/mount/chroot/ptrace/acct/sysctl), nothing that fork-bombs or sleeps
# long. The goal is broad core-syscall coverage that can't wedge the guest.
